## Необходимо реализовать:

1. **Инициализация решетки**: Заполнение спиновой системы случайными значениями (+1 / -1).
2. **Расчет энергии**: Вычисление суммарной энергии системы в процессе симуляции.
3. **Вывод в файл**: Сохранение рассчитанных значений энергии в текстовый файл.
4. **Модульность**: Вынос логики сохранения данных в отдельный исходный файл.
5. **Класс `Data_work`**: Создание и внедрение класса (или модуля) `Data_work` для обработки и записи выходных данных.
